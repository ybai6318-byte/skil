# 强制流程（按序执行）

## Step 1 估每句台词时长（查表速判，不做算术）

> **⛔ 算力红线（必须遵守，违反即错误执行）：**
> - **严禁**逐字数标点、严禁套 `字数/语速` 或 `×0.2` 任何乘除公式、严禁写 Python/代码算时长、严禁在推理里写出任何算式。
> - **严禁**为一句台词反复换语速档重算（"用2.8还是3.5"这种纠结是禁止的）。一句台词只查表一次，3秒内定档。
> - 整集所有台词的时长判断，加起来不应超过十几秒的思考量。如果你发现自己在算数、纠结档位、或想写脚本——**停下，直接查下表读秒数**。

**不要逐字数标点、不要套乘除公式。** 按"情绪选档 → 估字数 → 查下表直接读秒数(已取整)"。一句台词3秒内估完。

**台词时长速查表**（横轴=大致字数，纵轴=语速档；表内数字=该拍秒数，已含标点和取整）

| 语速档（情绪） | ≤10字 | 11-18字 | 19-26字 | 27-34字 | 35字+ |
|---|:---:|:---:|:---:|:---:|:---:|
| 慢（濒死/虚弱/哽咽/悲伤，约2字/秒） | 4s | 7s | 拆 | 拆 | 拆 |
| 中（沉重/正常/平静，约4字/秒） | 3s | 4s | 6s | 7s | 拆 |
| 快（紧张/激动/争吵，约6字/秒） | 2s | 3s | 4s | 6s | 7s |
| 极快（怒吼/咆哮/惊恐，约8字/秒） | 2s | 2s | 3s | 4s | 5s |

读表规则：
- "拆"= 该句时长会超过8.25s上限，**必须拆段或拆句**，不给单拍。
- 表内秒数已是"向上取整含标点"的结果，直接用，不再加减。
- 拿不准字数时往大估一档，宁长勿短。
- 中文要点：愤怒压抑的狠话归"快"(约6字/秒)；失控怒吼才归"极快"(约8字/秒)。

**判断动作**（只看两条，秒读完）：
- 表里读出 ≥6s 或落在"拆" → 触发拆段/拆句
- 读出 >5s → 触发反应插入法（见Step2）
- 读出 ≤5s → 单拍即可

**对白占比**：单段台词秒数合计 ≤8.25s(约55%)；明显超过就拆段。无需精确算百分比，凭表内秒数相加估即可。

## Step 2 分配时间拍

- **单拍时长**：台词拍直接用Step1速查表读出的秒数；纯动作拍按动作繁简估2-4s。两者同拍时取大的那个。不做精确计算。
- **长台词反应插入法（台词时长>5s时必须使用，不得用单一长拍硬扛）**：
  不把长台词塞进一个长拍，而是用「说话者拍 → 听者反应拍 → 说话者拍」承载同一句台词。台词逐字连续不拆，镜头在2-3个各≤5s的拍间切换；反应拍写听者的表情/动作（不复述台词）。
  例：陈二虎一句6s狠话 → 3s(陈二虎说前半句) + 2s(切苏婉惊惧反应，台词继续画外) + 2s(切回陈二虎说完) = 7s，无单拍超5s且台词完整。
- **时间标签 = 这一拍的时长(持续多少秒)，不是起始时间戳**
- **所有时间拍的时长相加必须 = 段总时长**（15秒段=15s，尾段=实际段长）
- 多句台词总时长>8.25s → 拆段

**标签写法（关键·常见错误）**：
- 正确（标签=时长，加总=15s）：`4s：…` `5s：…` `5s：…` `1s：…`（4+5+5+1=15）
- 错误（标签=累计起始时间戳）：`0s：…` `4s：…` `9s：…` `14s：…`（这是时间点不是时长，禁止）
- 检查：把每拍标签的数字加起来，必须等于段长；不等就是写错了。

## Step 3 写空间位置（仅每段首拍，后续拍严禁重复）

**位置只在每段第一个时间拍交待一次。** 首拍（Xs）写明每个在场人物：位置(左/右半区/中央) + 面向(朝左/右/画内/画外) + 景深(前/中/后景) + 关键视觉特征 + 状态。

**第2拍起严禁再写半区/站位**（左半区、右半区、画面中央等），只写景别/动作/情绪/焦点。镜头自然跟随主体，无需每拍重新定位。
- 错误（每拍都写位置，且前后矛盾）：首拍"苏婉右半区" → 第3拍"苏婉左半区" → 第4拍"苏婉画面中央"（位置反复+自相矛盾，禁止）
- 正确：首拍一次写全各人位置；后续拍只写"切到苏婉，她眼含热泪…"，不再标半区

段间衔接：下段首拍位置**从上段整段事件结果自然承前**，禁止元注释（承接上段、【段末位置】等）。

## Step 4 每拍写情绪表情

每个时间拍（含非台词拍）必须写人物情绪状态和表情。

# Seedance 2.0 适配规则（强制·影响生成质量）

Seedance 2.0 是自然语言模型，结构隐含公式「主体+动作+环境+镜头+光线/情绪+风格」，重点放最前，镜头描述最有影响力。每个15s片段独立生成。

1. **时间拍用流畅自然语言**，禁用 `[人物][情绪][语气]：` 方括号标签和多余符号。情绪/语气/音量/呼吸揉进句子。
2. **每拍聚焦一个核心动作**（一拍一动词），不堆叠多动作或冲突运镜。**单拍建议≤5s**：动作镜头超5s易拖沓重复；台词超5s用反应插入法（见Step2），不靠单一长拍硬扛。
3. **每段3-4拍，最多1-2句台词**；维持原段数时单段可稍密，但单拍仍只一个核心动作。
4. **镜头语言前置**：每拍先写景别+角度+运镜，再写动作与光影。
5. **不支持负面提示词**：取消负面字段，改写正面「画面约束」+质量后缀（见下）。
6. **光影色调写完整光照描述句**：光源+方向+质感 → 色彩绑定到具体载体，不做孤立色卡罗列。

# 输出格式

```text
【分段方案】（多段时）
第1段：[功能] / 第2段：[功能] / 尾段：[剩余，可短]

【第N段 Seedance 2.0 提示词｜15秒】
整体风格：[主风格 + 最多两个辅助质感]
光影色调：[完整光照描述句]
镜头质感：[焦段、景深、颗粒等全段统一参数]
场景：[时间，内外，地点]
人物：[本段出场角色]

[时长s]：[景别，角度，运镜。各人物位置+面向+景深+特征(仅首拍)。一个核心动作。打光/光影。情绪表情。焦点。环境声。]
[时长s]：[景别，角度，运镜。一个动作。光影变化。情绪表情。焦点。台词处：自然语言写情绪+语气+音量+呼吸，紧接引号原文台词。音效。]
[时长s]：[同上结构]
[时长s]：[同上结构，以声音/动作钩子收尾]
（各拍时长相加 = 15s）

画面约束：[正面陈述，逗号串接] + [一致性约束] + [质量后缀]

【连续性提示】（多段时）
- 角色/道具/环境：[状态变化]
```

**时间标签 = 该拍时长，非起始时间戳**。格式强制 `Xs`（如 4s/5s），禁止累计时间戳(0s/4s/9s)、范围(0-3s)、中文秒(0-3秒)。**所有标签数字相加 = 段长(15)**。
示例（15秒段，4拍）：`4s + 5s + 5s + 1s = 15s` ✓

# 风格块规则（三段式）

**整体风格**：只写艺术风格分类（如：写实电影，港片质感）。禁止混入色调(冷/暖)、质感(电影级/高清)、光效(逆光/氛围光)。完整目录见 references/style-catalog.md。常用短剧风格：写实电影 / 港片质感 / 韩系都市 / 国风水墨 / 2D漫剧 / 怀旧电影感 / 黑白胶片Noir。

**光影色调**：写成一句完整光照描述句——光源+方向+质感 → 色彩绑定到具体载体（土墙/衣料/地面反光/皮肤/窗格）。
- 错误（色卡罗列）：`硬侧光，墨绿，玄青，焦茶，朱砂红点缀`
- 正确（描述句）：`正午硬质侧光，阴阳脸高反差冷暖对冲；夯土墙焦茶暖调与阴影玄青冷调相压`
- **全局色调须可跨段复用，禁含单拍/单角色细节**（如"某人衣服一点红被提亮"应写进对应时间拍，不写全局）。
- **同一场景的各段，光影色调必须逐字一致**（同一句原样复制到每段开头）。光随剧情的变化只写进时间拍，不改全局色调句。换场景才换色调句。
- 情绪基调参考：希望/治愈=高调柔光暖白；危机/背叛=硬侧光阴阳脸冷暖对冲；绝望=低调顶/底光冷蓝压暗；商业=冷青垫底暖橙轮廓光；中式悲剧=格栅窗硬阴影土墙焦糖墨绿点朱砂红。

**镜头质感**：焦段+景深+颗粒+质地，如`电影级质感，35mm焦段，浅景深，轻微胶片颗粒`。禁写"3D CG渲染"。

时间轴内的动态光变（剧情驱动）写进对应拍，不只写在开头。

# 台词规则

- 用户原台词**逐字保留**，不改写/压缩/润色/翻译/替换（含引号、省略号、问号等标点）
- 每句台词前用**自然语言**写五要素（情绪+语气+音量+呼吸+表情），再紧接引号原文。禁用方括号标签。
- 正确：`林深呼吸急促、声音发虚、语速极慢地颤声问："……你……是谁？"`
- 错误：`[林深][虚弱][气声]："……"` 或 `林深："……"`

# 表情规则

每拍（含非台词拍）必须写情绪表情。
- 正确（非台词拍）：`九尾狐神情从玩味渐变阴冷、嘴角笑意消失`
- 错误：`九尾狐尾巴升起显形`（无表情）

# 镜头-空间一致性

- **位置只首拍写一次，后续拍严禁重复半区/站位**（否则易前后矛盾）
- **对峙（强制）**：机位偏向一侧，**一人正脸面对镜头方向、另一人背对镜头露出后脑或侧肩入画**。严禁两人都侧脸/四分之三侧脸对着镜头（如"A右半区面向画左、B左半区面向画右"这种双侧脸对峙是错的）。需展示背对者的表情时，另起一拍切到他的正面反应镜头。
- POV主观视角：只描述该角色所见，不描述其自身表情；过肩镜头入画的后脑/肩属视角主体，不描述其正面表情。需展示其反应则另拍外部镜头。
（细则见 references/director-shot-design.md）

# 画面约束（替代负面提示词·Seedance不支持负面词）

把负面项翻成正面陈述 + 固定质量后缀：

**正面约束模板**：
`画面清晰锐利曝光均衡，人物结构正常脸部稳定不变形五指正常，口型与台词同步，动作连贯流畅画面稳定无跳帧，光照方向统一；人物脸部跨镜头一致不随视角光照变形，发型服装连续，角色称呼不混指，主体清晰不因运镜丢失，同场景光照天气时间不突变，道具跨镜头连续，音效嵌入时间拍不单独成段台词与背景音层次分明`

**质量后缀（固定附末尾）**：
`4K超高清，细节丰富，画面锐利清晰，电影级质感，色彩自然，光照柔和，画面稳定无重影无闪烁，动作自然流畅`

**文字规则**：默认写"生成无字幕无水印logo的画面"；剧情关键文字（相机屏幕/手机信息/牌匾）需显式指定内容、时机、位置。

# 禁止项

1. 禁止元注释（【段末位置】、承接上段、从上一段末延续）
2. 禁止分析性文字（镜头目的为、目的是）
3. 禁止单独声音区块——声音嵌入每拍
4. 禁止重复台词（时间拍写过不再单列）
5. 禁止虚词（高级感、镜头丰富）
6. 禁止尾段硬凑15秒
7. 禁止改写用户台词
8. 禁止在时间拍写计算过程（如 时长=25/6.0+0.8=4.97s）
9. 禁止方括号标签格式（Seedance不友好）
10. 禁止负面提示词（改正面约束）
11. 禁止光影色调写孤立色卡罗列或单角色细节
12. 禁止时间标签用累计起始时间戳(0s/4s/9s)——标签必须是该拍时长，且各拍相加=段长
13. 禁止在第2拍及之后重复人物半区/站位（位置只首拍交待一次）
14. 禁止双侧脸对峙（两人都四分之三侧脸朝镜头）——必须一人正脸一人露后脑
15. 台词时长>5s必须用反应插入法，禁止塞进单一长拍
